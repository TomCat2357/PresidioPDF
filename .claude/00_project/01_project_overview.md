# PresidioPDF プロジェクト概要

## プロジェクトの目的
日本語の個人情報検出・マスキングツールのPDF文書向け実装。SudachiPy（形態素解析）を活用したセキュリティとプライバシー保護のためのツール。

## コアバリュー
- **プライバシー保護**: 日本語個人情報の正確な検出と適切なマスキング
- **使いやすさ**: CLIとGUI（PyQt）両方の提供
- **高精度**: SudachiPy 辞書（core/full）と分割モードによる柔軟な調整
- **拡張性**: モジュラー設計による機能拡張の容易さ

## 技術スタック
- **言語**: Python 3.14（`>=3.14,<3.15`）
- **依存関係管理**: uv
- **NLP**: SudachiPy（形態素解析・固有名詞NE）
- **OCR**: RapidOCR v3（軽=mobile / 重=server の2モデル）
- **PDF処理**: PyMuPDF
- **Webフレームワーク**: Flask
- **テスト**: pytest
- **品質**: black (フォーマット), mypy (型チェック)
